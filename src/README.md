# Python Text Editor — Исходный код

Простой текстовый редактор на Python, реализованный с помощью стандартной библиотеки Tkinter.

## Запуск

```bash
cd src
python main.py
```

**Требования:** Python 3.10+. Tkinter входит в стандартную поставку Python — дополнительная установка не нужна.

## Структура файлов

```
src/
├── main.py      — точка входа, запускает приложение
└── editor.py    — основной класс TextEditor со всей логикой
```

## Архитектура

```
TextEditor (наследует tk.Tk)
│
├── _build_menu()         → строка меню (Файл / Правка / Вид / О программе)
├── _build_editor()       → виджет Text + Scrollbar
├── _build_statusbar()    → нижняя строка состояния
├── _bind_shortcuts()     → горячие клавиши
│
├── Файловые операции
│   ├── new_file()
│   ├── open_file()
│   ├── save_file()
│   └── save_as()
│
├── Редактирование
│   ├── _undo() / _redo()
│   ├── _cut() / _copy() / _paste()
│   └── _select_all()
│
├── Поиск
│   └── find_text()       → поиск с подсветкой (tag_add / tag_config)
│
├── Темы
│   ├── THEMES = {"dark": {...}, "light": {...}}
│   ├── _switch_theme(name)
│   └── _apply_theme()
│
└── Служебные
    ├── _update_statusbar()
    ├── _on_text_modified()
    ├── _confirm_discard()
    └── _show_about()
```

## Используемые модули Python

| Модуль | Назначение |
|--------|-----------|
| `tkinter` | Главное окно, виджеты, меню |
| `tkinter.filedialog` | Диалоги открытия/сохранения файлов |
| `tkinter.messagebox` | Диалоги предупреждений и ошибок |
| `tkinter.simpledialog` | Диалог ввода строки поиска |
| `os` | Получение имени файла из пути |

## Принципы реализации

- **ООП:** весь редактор — один класс `TextEditor(tk.Tk)`, состояние хранится в атрибутах
- **Event-driven:** действия пользователя обрабатываются через `bind()` и команды меню
- **Разделение ответственности:** построение UI (\_build\_\*), логика файлов, логика редактирования — отдельные методы
- **Безопасность данных:** при закрытии или открытии нового файла проверяется наличие несохранённых изменений

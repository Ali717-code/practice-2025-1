### Этап 3. Разработка текстового редактора

Разработан полнофункциональный текстовый редактор на Python с использованием библиотеки Tkinter.

#### Архитектура

Приложение построено по принципу ООП. Класс `TextEditor` наследует от `tk.Tk`:

```python
class TextEditor(tk.Tk):
    def __init__(self):
        super().__init__()
        self._build_menu()
        self._build_editor()
        self._build_statusbar()
        self._bind_shortcuts()
```

#### Реализованные функции

| Функция | Горячая клавиша | Описание |
|---------|----------------|----------|
| Новый файл | Ctrl+N | Создание пустого документа |
| Открыть | Ctrl+O | Диалог открытия файла |
| Сохранить | Ctrl+S | Сохранение текущего файла |
| Сохранить как | Ctrl+Shift+S | Сохранение с новым именем |
| Отменить | Ctrl+Z | Отмена последнего действия |
| Повторить | Ctrl+Y | Повтор отменённого действия |
| Вырезать | Ctrl+X | Вырезать выделенное |
| Копировать | Ctrl+C | Копировать выделенное |
| Вставить | Ctrl+V | Вставить из буфера |
| Выделить всё | Ctrl+A | Выделить весь текст |
| Поиск | Ctrl+F | Поиск с подсветкой |

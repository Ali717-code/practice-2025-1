## Вариативная часть задания

**Тема:** Python: Create a Simple Python Text Editor!

Задание выбрано из коллекции проектов [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) на GitHub. В рамках задания разработан полнофункциональный текстовый редактор на языке Python с использованием библиотеки Tkinter.

**Функциональность редактора:**
- Создание, открытие и сохранение файлов
- Операции редактирования: вырезать, копировать, вставить, отменить/повторить
- Поиск по тексту с подсветкой найденных вхождений
- Переключение тёмной/светлой темы
- Строка состояния (число строк, слов, символов)
- Полная поддержка горячих клавиш

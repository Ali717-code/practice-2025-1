Python: Create a Simple Text Editor

Изучение разработки настольных GUI-приложений на Python с использованием библиотеки Tkinter на примере текстового редактора.

🎯 О теме задания

Тема выбрана из коллекции проектов Build Your Own X на GitHub. Задание предполагает самостоятельную реализацию полноценного текстового редактора на языке Python, изучение принципов GUI-программирования и применение навыков объектно-ориентированного программирования.

Что такое текстовый редактор

📖 Теоретическая база

Текстовый редактор — это программное обеспечение, предназначенное для создания и редактирования текстовых файлов. В отличие от текстовых процессоров (Microsoft Word, LibreOffice), текстовые редакторы работают с «чистым» текстом без форматирования.

Примеры текстовых редакторов: Notepad (Windows), gedit (Linux), VS Code, Sublime Text, Vim, Emacs. Понимание устройства текстового редактора помогает глубже освоить принципы программирования GUI-приложений, работы с файловой системой и обработки пользовательского ввода.

Что такое Tkinter

📦

Стандартная библиотека

Tkinter входит в стандартную поставку Python — не требует дополнительной установки. Доступен на всех платформах: Windows, macOS, Linux.

🪟

Виджеты

Tkinter предоставляет широкий набор готовых виджетов: кнопки, поля ввода, текстовые области, меню, диалоговые окна и многое другое.

🔗

Event-driven

Программирование на основе событий: каждое действие пользователя (клик, нажатие клавиши) вызывает соответствующую функцию-обработчик.

🎛️

Компоновщики

Три способа расположения виджетов: pack (последовательно), grid (таблица), place (абсолютные координаты).

Ключевые концепции

  • 🏗️
    Объектно-ориентированный подход: приложение строится как класс, наследующий от tk.Tk. Инкапсуляция логики и интерфейса в одном объекте упрощает сопровождение кода.
  • 📜
    Виджет Text: основа редактора — многострочное текстовое поле с поддержкой тегов, маркеров и операций поиска/замены. Позволяет форматировать выделенные фрагменты.
  • 📂
    Работа с файловой системой: модули os, pathlib и filedialog позволяют открывать, сохранять файлы через системные диалоги.
  • ⌨️
    Горячие клавиши: метод bind() позволяет назначать обработчики на клавиши и их комбинации (Ctrl+S, Ctrl+O и т.д.).
  • 🍽️
    Меню приложения: класс Menu позволяет создавать строку меню с вложенными пунктами и разделителями.
  • 🔄
    Главный цикл: метод mainloop() запускает цикл обработки событий — программа «ждёт» действий пользователя и реагирует на них.

Пример кода

Базовая структура текстового редактора на Python

import tkinter as tk from tkinter import filedialog, messagebox class TextEditor(tk.Tk): def __init__(self): super().__init__() self.title("Python Text Editor") self.geometry("900x600") self.current_file = None self._create_menu() self._create_editor() def _create_editor(self): # Создание текстовой области с прокруткой frame = tk.Frame(self) frame.pack(fill=tk.BOTH, expand=True) scrollbar = tk.Scrollbar(frame) scrollbar.pack(side=tk.RIGHT, fill=tk.Y) self.text_area = tk.Text( frame, yscrollcommand=scrollbar.set, font=("Consolas", 12), wrap=tk.WORD ) self.text_area.pack(fill=tk.BOTH, expand=True) scrollbar.config(command=self.text_area.yview) def open_file(self): path = filedialog.askopenfilename( filetypes=[("Text files", "*.txt"), ("All files", "*.*")] ) if path: with open(path, "r", encoding="utf-8") as f: self.text_area.delete(1.0, tk.END) self.text_area.insert(tk.END, f.read()) self.current_file = path self.title(f"Python Text Editor — {path}") if __name__ == "__main__": app = TextEditor() app.mainloop()

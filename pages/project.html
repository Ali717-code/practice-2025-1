Этапы разработки

Проект разбит на 5 последовательных этапов, каждый из которых добавляет новую функциональность

⚙️ Этап 1: Основной каркас приложения

На первом этапе создаётся базовая структура приложения: главное окно, текстовая область с полосой прокрутки и строка состояния. Реализован объектно-ориентированный подход — весь редактор инкапсулирован в класс TextEditor.

  • ✅
    Класс TextEditor — наследует от tk.Tk, хранит состояние приложения (текущий файл, признак изменений).
  • ✅
    Виджет Text — многострочная область редактирования с настроенным шрифтом Consolas 12pt и автоматическим переносом слов.
  • ✅
    Строка состояния — нижняя панель с отображением числа строк, слов и символов, обновляемых в реальном времени.
tk.Tk tk.Text tk.Frame Scrollbar

📂 Этап 2: Работа с файлами

Реализованы операции создания нового файла, открытия существующего и сохранения текущего документа. Для диалогов открытия/сохранения используется модуль tkinter.filedialog. При наличии несохранённых изменений пользователь получает предупреждение.

  • 📄
    Новый файл (Ctrl+N) — очистка текстовой области с проверкой несохранённых изменений.
  • 📂
    Открыть файл (Ctrl+O) — диалог выбора файла с фильтром по расширению (.txt, .py, .md и др.).
  • 💾
    Сохранить (Ctrl+S) — сохранение в текущий файл; если файл новый, открывается диалог «Сохранить как».
  • 💾
    Сохранить как (Ctrl+Shift+S) — диалог выбора имени и пути нового файла.
filedialog messagebox open() encoding=utf-8

✂️ Этап 3: Меню и операции редактирования

Создана полноценная строка меню с тремя разделами: «Файл», «Правка» и «Вид». Реализованы стандартные операции редактирования через меню и горячие клавиши.

  • 🍽️
    Строка меню — разделы «Файл», «Правка», «Вид» с вложенными пунктами и разделителями.
  • ✂️
    Вырезать/Копировать/Вставить — Ctrl+X, Ctrl+C, Ctrl+V через буфер обмена системы.
  • ↩️
    Отмена/Повтор (Ctrl+Z / Ctrl+Y) — многоуровневая история действий через встроенный механизм виджета Text.
  • 🔠
    Выделить всё (Ctrl+A) — мгновенное выделение всего содержимого документа.
tk.Menu bind() event_generate

🔍 Этап 4: Поиск и смена темы

Реализованы расширенные функции: диалог поиска с подсветкой найденных вхождений и переключение между светлой и тёмной темой оформления.

  • 🔍
    Поиск (Ctrl+F) — всплывающее окно поиска. Найденные фрагменты подсвечиваются жёлтым цветом через теги виджета Text.
  • 🌙
    Тёмная тема — фон #1e1e1e, текст #d4d4d4 — стиль VS Code для комфортной работы в темноте.
  • ☀️
    Светлая тема — белый фон и чёрный текст для работы при дневном освещении.
tk.Toplevel text.tag_add() text.tag_config() configure(bg=)

🎨 Этап 5: Финальная полировка и документация

Добавлены иконка приложения, всплывающие подсказки, диалог «О программе» и написана полная документация к коду. Проведено тестирование на всех поддерживаемых платформах.

  • ℹ️
    Диалог «О программе» — версия, имя автора, используемые технологии.
  • 💬
    Docstrings — документация ко всем методам и классам в формате Google-style.
  • 🧪
    Тестирование — проверка работы на Windows 10/11 и Linux Ubuntu 22.04.
